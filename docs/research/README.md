# Research

The research behind Drive Lab, written before and during the build (2026-10-27/28): the plan, the
vehicle dynamics, the Aventador SVJ's data, how the car model, audio and references were sourced,
Roblox engine facts, how sims use real data, the import pipeline, materials and the wet look, and
the roadmap. Copied from the owner's notes (`rbx-game-kit/research_notes/Drive lab/`, never
committed there) so they live with the project; the image folders (model candidates, reference
pack, video frames) stay outside the repo in the owner's working files.

These are research notes, dated where they say so: the code and `games/drive-lab/README.md` are
the current truth when they disagree.
